# T7 independent checker gate parity

Criterion: the set each check rejects covers the set the corresponding production gate rejects. A
rejection that cannot be traced to the `fstab` or `cmdline.txt` content the production script
writes, or to a gate's explicit reject condition, is outside the contract and is not grounds for a
code change here.

Line numbers on both sides refer to the working tree at the time this table was written; the
`t7_verify.sh` column was measured after the parity fixes this table records as `fixed`. Rounds
since then have moved several of them (measured 2026-09-09), so the quoted text and the
surrounding gate name are the reliable anchors, not the number. Re-measuring the whole table is
outstanding work.
